# 🍔 Food Delivery Data Analysis using Python

## 📌 Problem Statement

The objective of this project is to perform **Exploratory Data Analysis (EDA) and Data Analysis** on a food delivery dataset to understand customer behavior, order patterns, restaurant performance, payment preferences, delivery fees, discounts, and customer ratings.

The project focuses on cleaning the dataset, identifying trends and patterns, and generating meaningful business insights using Python.

---

## 📊 Dataset

- **Rows:** 741,600
- **Columns:** 22
- **Domain:** Food Delivery

---

## 🛠️ Tools & Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 🔄 Project Workflow

- Data Understanding & Inspection
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Categorical Data Standardization
- Skewness Analysis
- Outlier Detection & Capping
- Univariate Analysis
- GroupBy Analysis
- Pivot Table Analysis
- Data Visualization
- Business Insights

## 📈 Key Analysis

- City-wise Order Analysis
- Restaurant Category Analysis

- Customer Demographics
- Order Value & Discount Analysis
- Delivery Fee Analysis
- Weather & Traffic Analysis
- Customer Rating Analysis

## 🏁 Conclusion

- Successfully performed **EDA and data analysis** on the food delivery dataset using Python.
- Cleaned the data by handling **duplicates, inconsistent values, missing values, skewness, and outliers**.
- Analyzed **cities, restaurants, payment methods, customers, weather, and traffic**.
- **Mumbai** had the highest average order value, while **Nagpur** had the lowest.
- **Stormy weather** had the highest average delivery fee.
- Overall, the analysis identified useful **customer, order, payment, and operational patterns**.
- These insights can help improve **pricing, discounts, customer experience, and delivery operations**.
